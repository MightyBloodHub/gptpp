# Same-failure retry ablation

Freeze the design using the v7 protocol and code before inspecting the new comparison. Use all 112 assigned v7 trials spanning both models, eight tasks and seven arms. Each original first call and its public diagnostic stay fixed. The subset condition is an actual first public mismatch or runtime failure in a named non-target caller. Require the archived excerpt retry to match the original renderer. Pass only the corresponding immutable GPT++ starter, caller and target names, public arguments and expected caller result to the checked obligation helper. Its exact result must imply a unique target value at one input. The original withheld outcome and whether the archived retry succeeded play no role in eligibility.

For every eligible exact result, make **one new local generation** after the transfer run. Retain the original failure, previous insertion, model, seed, temperature, limits, transport and suffix. Replace just the original read-only caller excerpts with the necessary scalar target fact using the transfer feedback renderer. Preserve v7 order. Identical facts in different assigned cells still receive their own generation. Unsupported retry cells and assignments that never retried retain their archived costs and decisions. If no exact facts are available, record the denominator and generate zero completions.

Evaluate the new completion with the same scoped patcher, public tests and withheld tests. Record the exact generation controls, text, counters, timing, computed fact, code fingerprint, judgments and upstream archive hash. Report old and new retry input and output counts, acceptance gains/losses, and full-workflow acceptance and input-plus-output per accepted change by model. Full-workflow results reuse the original first calls and untouched cells; they are paired substitutions in an archived cohort. Models have distinct tokenizers. Small counts, one sample per arm, preselection by caller failure and new-vs-archived timing limit generalization. The broader development and transfer comparisons do not isolate this intervention.

Run `retry_obligations.py --plan` to count eligible retries without inference. Pass `--collect` after the transfer run and `--replay` to recompute every new judgment without a model; both accept an archive filename. `--report` renders the paired tables from a complete archive. Use the configured benchmark Python environment and run from the repository root.
