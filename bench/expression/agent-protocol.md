# Generating an expression with public feedback

Use all three historical development tasks, all three language implementations and both model digests from the archived numbered catalog study. Use the archived assignment order. These previously inspected projects measure development behavior. No cross-project generalization or language-wide efficiency claim is inferred.

The agent receives the original target, bounded read-only caller excerpts, the change request, original results and expected results for all three public examples, and the native source expressions listed by ID. Supply equivalent syntax help for conditional expressions, Boolean operators and integer division in each language. The schema requests one site ID and one new native expression. Use an ordinary Ollama prompt, a 4,096-token context, greedy decoding and a 240-token output ceiling. Attempt one uses seed 42. A failed selection, compiler check, execution or public test gets one retry with seed 43, the rejected response and at most 600 characters of actual diagnostic text. A public pass ends generation even if withheld tests later fail. No oracle labels, hand-selected location, repair menus or task-specific syntax templates are available.

Use the real agent-edit CLI for GPT++. Use the same renderer and retry controller with the existing Python/Rust checked edit adapters and macOS sandboxed evaluation. Count all input and generated tokens, failed trials, public rejections, initial and final acceptance, workflow wall time and model round-trip time. The scorer runs after the model workflow and is timed separately. A patch is accepted only after every withheld check passes. Publish all requests, model response text, usage and patch hashes, plus a replay command. Compare with the prior one-shot numbered catalog as an archived control. The workflows differ in caller context, syntax guide, public observations, and retry policy together.

For this benchmark each arm starts directly in free-generation mode. A user of GPT++ can invoke the same tool when bounded enumerative search finds no candidate. The benchmark does not charge or compare a preliminary enumerative search.
