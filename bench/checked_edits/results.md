# Can a checked edit save a model call?

**Yes, for three of six fresh GPT++ assignments.** Compiler-only search and the opt-in workflow both published correct edits for signed net weight, proof-sheet padding and the mirror carriage. Direct Qwen solved net weight. Adding a bounded model repair to search cost three calls and recovered zero additional GPT++ edits. The paired workflow gains were `proof_sheet` and `mirror_carriage`. No direct GPT++ success was lost. The observed preparation-inclusive token saving was **71.1%**. The preregistered target required at least 20% savings with acceptance no more than two percentage points worse. The paired correctness difference was +33.3 percentage points, with a conservative 95% interval of −48.8 to +81.6. One third of paired family resamples had zero direct successes, giving the cost ratio no finite upper 95% bound. **The pilot does not establish the target.** [Decision criterion and uncertainty method](protocol.md)

Each standalone arm was charged 167 elapsed seconds to prepare six public specifications and 24 labels, plus the six shared Qwen contract-audit calls (1,468 input and 84 output tokens). Two audit edits passed the examples and were refuted by the stronger property. The deterministic bad control failed each of the six properties, and each positive reference passed. The fresh run used 89 trial calls, 35 repairs and no extra specification labels. Contract authoring tokens and human-equivalent time were unmetered. Wall times reflect this host and its concurrent load. [Source freeze](freeze.json) · [Charged setup, tool, model and scoring time](run/results.md)

## What the counterexamples changed

* **Historical decision replay, zero new calls.** Piecewise scored 4/11, archived direct Qwen 7/11 and piecewise-first fallback 5/11. The fallback recovered `more20`. It replaced correct Qwen results on `makes10` and `nearHundred` and published a wrong `posNeg` where Qwen had abstained. [Replay command and development evidence](README.md)
* **New development repairs.** On `makes10`, swapping the arguments changed true to false. Qwen’s repair dropped the previously working right-ten case. The weak right-ten contract alone also accepted the original wrong implementation. On `posNeg`, both historical systems missed the change. Given the public counterexample (−8, 0, true), the repair still returned true. Both repairs were withheld. [Symmetry, proof and weak-contract receipts](../../examples/makes10/development.json) · [Historical miss and live repair](dev_posneg_capture.json)
* **Caller-visible failure.** With one seat, reserve A, cancel A, reserve B, then reopen A. The first divergence was at step four. The expected state had A cancelled, B active and zero seats free, with a sold-out reply. The defective library returned success with both IDs active. The corrected library passed the same SQLite/Python and Rust clients and 1,022 public assignments. [Shortest witness and both client snapshots](../../examples/reservations/reopen-witness.json)
* **Fresh transfer.** On `service_gap`, both the one-call model and compiler-only search failed in all three languages. A compiler proposal allowed service at coincident anchors (−3, −3). Given that mismatch against the one-unused-position rule, Qwen produced `abs(left - right) == 2` in both typed Python and Rust. Both passed all 420 independent scoring inputs. In the direct Python retry comparison, supplying the public witness also recovered this edit while the blind retry failed. The fresh GPT++ repair failed. [Per-language trial receipts](run/decisions.jsonl) · [Independent scores](run/scores.json)

**Matched-helper check.** The frozen GPT++ prompt advertised `abs(x)` without supplying it. We identified the mismatch during collection and pinned a supplemental check before reading the sealed scores. Adding the helper changed the final GPT++ `service_gap` rejection from an undefined function to a replayable wrong answer on (0, 2). Rechecking all 90 assignments reproduced every independent outcome. All 89 trial prompts and six preparation prompts matched their archived requests exactly, so the repeat used zero new inference calls. This uses the same six families. [Matched-helper results](matched_run/results.md) · [Supplemental protocol](matched_protocol.md)

The compiler can discharge a named property on its declared domain, distinguish example agreement from verification, replay a violating observation and withhold an unresolved edit. A passing weak property can still miss the intended behavior. A model can propose another expression. An authorized reference or person must supply missing semantics when surviving candidates disagree. Given six synthetic families, one model and no measured GPT++ repair gain over compiler-only search, **keep the workflow opt-in**.
