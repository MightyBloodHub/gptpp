The other five exercise stateless predicates or numeric rules. The prompt shows the task statement, native function signature, prior expression and every public argument/answer pair. Public cases use a frozen deterministic seed with boundary examples and balanced Boolean labels. All remaining tuples in the declared direct domain and every event history are withheld. Reject an entire assignment on any disagreement or runtime fault. The nine tasks form the denominator regardless of failure, search complexity or observed result. Preflight each starter and independent reference on all backends and disclose any task where the starter already fits the examples. Never use withheld outcomes to select, repair or break ties. End-state histories can revisit previously tested scalar transitions and are not independent task replicates.

Primary endpoint: number of tasks for which a selected, fully type-checked completion passes every public and withheld check, by solver. Report paired wins, losses and ties on identical tasks, ambiguity, incompleteness, published incorrect edits, candidates and actual elapsed wall time.
