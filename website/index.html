The language

Change a function.
Check the program.

GPT++ gives AI-assisted maintenance a small, statically typed language and a compiler that runs locally.

Focused edits
Replace a function body or one expression. Preview the patch and apply it against the source revision you reviewed.
Independent checks
Type-check the module and run behavioral cases against the edited function and its callers.
Offline execution
Run a .gpp module with the reference interpreter or build a native executable with LLVM.

Quickstart

Run your first .gpp file.

Clone the project, build gpp with the pinned Rust toolchain, then check and run the sample. The interpreter prints 42.

Read the language reference

examples/add.gpp

module demo.main;

fn add(left: I64, right: I64) -> I64 !{} {
    return left + right;
}

pub fn main() -> I64 !{} {
    return add(20, 22);
}

Build and run

git clone https://github.com/MightyBloodHub/gptpp.git
cd gptpp
cargo build --locked --offline
target/debug/gpp check examples/add.gpp
target/debug/gpp run --interpreter examples/add.gpp

Output 42

How much model work does a correct edit take?

GPT++ tracks tokens per accepted change. The benchmark protocols and results are public, along with the source code and roadmap.

Benchmark results · November 2026

Editing a single expression

We tested Qwen2.5-Coder 7B and StarCoder2 3B on historical fixes from Redis, FastLED and Go. Each task supplied the target function and exercised two caller paths. The numbered-expression follow-up reused the same three tasks.

The main Qwen test charged for finding the expression and editing it. All three languages accepted zero changes, so tokens per accepted fix were undefined. The next experiment will test whether values observed during failing public examples help the model choose and repair the faulty expression.
